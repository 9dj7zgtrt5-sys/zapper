# TV home screen (from CleanYourTV)

This folder is the launcher from https://github.com/Gathin23/cleanyourtv (commit 3c122bc, MIT licence, see
LICENSE-cleanyourtv.txt; fonts OFL, icons Fluent Emoji MIT). It is built by this repo's GitHub workflow and
signed with Zapper's key; the only change is the signing config. The home screen's apps, wallpaper and the
"open Zapper at start-up" behaviour come from the theme pushed by `home-setup.sh`.
